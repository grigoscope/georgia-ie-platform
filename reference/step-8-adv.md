# Этап 8. Docker Compose, тестирование и развёртывание

## Критерии достижения

1. Приложение собирается Docker.
2. Все сервисы запускаются одной командой.
3. Миграции применяются.
4. Тесты запускаются в контейнере.
5. Frontend собирается.
6. Worker и Beat работают.
7. Есть production-инструкция.
8. Секреты не встроены в образ.

## Сервисы Docker Compose

- backend;
- frontend;
- postgres;
- redis;
- celery-worker;
- celery-beat;
- nginx.

Опционально:

- flower;
- тестовый mail service;
- object storage emulator.

## Требования к образам

- отдельные Dockerfile;
- непривилегированный пользователь;
- кеш зависимостей;
- healthcheck;
- production server;
- сбор static;
- media в volume или object storage;
- `.env` не копируется в образ.
