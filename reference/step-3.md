# Этап 3. Журнал доходов, валюты, отчёты и инвойсы

## Критерии достижения

1. Работает CRUD доходов.
2. Реализован GEL-эквивалент.
3. Исторический курс фиксируется.
4. Работают графы 18–21.
5. Есть месячные и годовые агрегаты.
6. Создаются налоговые периоды.
7. Генерируется PDF-инвойс.
8. Оплата инвойса связывается с доходом.
9. Логика покрыта unit-тестами.

## 1. Конвертация

Реализовать:

- GEL без конвертации;
- автоматический фиатный курс;
- ручной курс;
- готовый GEL-эквивалент;
- ручную оценку криптовалюты;
- проверку источника и даты;
- Decimal;
- единое округление.

Сервис возвращает исходную сумму, валюту, курс, единицу, GEL, источник, дату и предупреждения.

При сбое внешнего источника доступен ручной режим. Доход с пустым GEL не сохраняется.

## 2. Создание дохода

1. Проверить владельца связанных объектов.
2. Рассчитать или проверить GEL.
3. Предложить категорию по счёту.
4. Получить подтверждение категории.
5. Сохранить.
6. Создать или обновить TaxPeriod.
7. Записать аудит.

## 3. Маппинг по умолчанию

- кассовый аппарат → 18;
- физический POS → 19;
- банк и безналичные способы → 20;
- бартер, крипта и прочее → 21.

Пользователь может изменить предложение после предупреждения.

## 4. Расчёты периода

- field_18 = сумма категории 18;
- field_19 = сумма категории 19;
- field_20 = сумма категории 20;
- field_21 = сумма категории 21;
- field_17 = сумма field_18–21;
- field_15 = сумма field_17 с января;
- field_26 = предварительный налог по ставке.

При нулевом месяце field_17 = 0, field_15 сохраняет накопленный итог.

## 5. Изменение прошлого периода

При изменении задним числом:

- пересчитать месяц;
- пересчитать field_15 следующих месяцев года;
- не снимать submitted автоматически;
- установить changed_after_submission;
- создать предупреждение.

## 6. Отчёты

Реализовать:

- dashboard;
- месячный;
- годовой;
- по счетам;
- по валютам;
- по контрагентам;
- по графам.

Удалённые записи не учитываются. Итог отчёта совпадает с TaxPeriod.

## 7. Экспорт

Минимум CSV, продвинутая часть XLSX.

Колонки:

- дата;
- описание;
- контрагент;
- счёт;
- документ;
- исходная сумма;
- валюта;
- курс;
- источник;
- GEL;
- графа;
- НДС;
- инвойс;
- комментарий.

## 8. Инвойс

Порядок:

1. Сформировать номер.
2. Скопировать продавца.
3. Получить покупателя.
4. Получить позиции.
5. Рассчитать итоги.
6. Скопировать реквизиты.
7. Сохранить черновик.
8. Сгенерировать PDF.

Расчёты:

- line_total = quantity × unit_price;
- subtotal = сумма позиций;
- total = subtotal - discount + extra_charge;
- справочный налог не меняет total, если платит исполнитель.

PDF проверяется на кириллицу, переносы, длинные адреса, много позиций, несколько страниц, подпись и реквизиты.

## 9. Оплата инвойса

Полная оплата:

- статус paid;
- дата;
- предложение создать IncomeEntry.

Частичная:

- partially_paid;
- InvoicePayment;
- доход на фактическую сумму;
- расчёт остатка.

Дата инвойса не становится датой дохода автоматически.
