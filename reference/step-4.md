# Этап 4. Реализация REST API

## Критерии достижения

Реализованы endpoints для:

- auth;
- профиля;
- Telegram;
- счетов;
- контрагентов;
- валют и курсов;
- доходов;
- отчётов;
- налоговых периодов;
- инвойсов;
- PDF;
- уведомлений;
- настроек.

Полный список находится в `api.md`.

## Авторизация

- закрытые endpoints требуют токен;
- access token ограничен по времени;
- refresh token отзывается;
- logout делает токен недействительным;
- reset password не раскрывает наличие email.

## Permissions

- пользователь видит только свои данные;
- доступ проверяется для списков и объектов;
- вложенные связи также проверяются;
- чужой объект не раскрывается.

## Валидация

- serializer проверяет формат;
- сервисный слой проверяет бизнес-правила;
- база имеет ограничения;
- ошибки единообразны.

## Фильтрация и пагинация

Обязательны:

- даты;
- месяц и год;
- счёт;
- валюта;
- контрагент;
- графа;
- статус;
- поиск;
- сортировка;
- пагинация доходов, инвойсов, уведомлений, контрагентов и аудита.

## Документация

OpenAPI содержит:

- параметры;
- request body;
- response;
- ошибки;
- примеры;
- авторизацию;
- перечисления.

## Тесты API

- 401 без токена;
- чужие данные;
- чужой счёт;
- неверная сумма;
- неверный курс;
- фильтры;
- пагинация;
- экспорт;
- mark-submitted;
- mark-paid;
- PDF;
- Telegram auth;
- идемпотентность;
- rate limiting.

## Критерий завершения

Все обязательные endpoints доступны через Swagger и проходят автоматические тесты.
